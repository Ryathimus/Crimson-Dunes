# Opening Route Draft — The Red Road to Crimson Dunes

## Current Agreed Direction

- Start date: 1810.
- Start mode: Outback / travel route.
- Route type: Semi-procedural.
- First locked POV: Waru.
- Waru role: local initiate.
- Waru situation: cautiously observing outsiders from a distance.
- Outsiders: mixed group connected to the emerging Crimson Dunes School.

## Narrative Function

The opening should introduce the player to the world through observation, tracking, land-reading, cautious inference, and indirect decision-making.

## Route Structure

```text
Beat 01 — Departure / threshold
Beat 02 — First environmental anomaly
Beat 03 — First character contrast
Beat 04 — Route complication
Beat 05 — First hint of Crimson Dunes
Beat 06 — Arrival threshold
```

## Slice 1 Minimal Route

Only three nodes are required for the first tracer bullet:

1. Red Dust Approach
2. Dry Creek Sign
3. Distant Smoke / Hidden Track

## First Encounter Pattern

**The Outsiders Disturb a Route Sign**

Fixed purpose:

- Demonstrates outsiders moving through a magically sensitive landscape without fully understanding it.
- Allows Waru to observe, interpret, avoid detection, indirectly intervene, or reveal themself.

Possible procedural variations:

- Outsiders misread a marked stone.
- Outsiders use wand magic near a dry creek.
- Outsiders unknowingly approach a protected boundary.
- Outsiders attract attention from something they cannot detect.
