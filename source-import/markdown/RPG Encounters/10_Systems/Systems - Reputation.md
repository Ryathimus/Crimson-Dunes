# Systems – Reputation & Faction Standing

  

Reputation gates outcomes and branches. Track as simple bands:

  

- **Renown:** −2 (Infamy), −1 (Unknown/Disliked), 0 (Neutral), +1 (Respected), +2 (Esteemed)

- **Faction Standing:** Maintain per faction (Sect, Town Guard, Merchants, etc.)

  

### Sample NPC Gates (Powerful Figure)

- **Mentor Offer:** Renown ≥ +1, Momentum ≥ 2, Conduct: Honorable or Loyal

- **Sect Invitation:** Renown ≥ 0, Momentum ≥ 1, Conduct not Brutal

- **Destroy You:** Renown ≤ −1 OR Conduct: Brutal/Deceitful with collateral harm

- **Ignore You:** Renown 0, Momentum ≤ 0, ambiguous Conduct
