# Systems – Encounter Variables & Modifiers

  

Variables adjust DCs, rewards, and NPC decisions.

  

## Common Variables

- **Environment:** Darkness (−2 Perception), Rain (−1 Ranged), Tight Quarters (+1 to AoE DC), Difficult Terrain (−10' speed).

- **Threats:** Roaming monsters (random check each 10 minutes), trap density (+2 to Trap-related DCs).

- **Population:** Bystanders (morale checks), guards on alert (+2 to social DCs).

- **Time Pressure:** Countdown tracks (e.g., 6 ticks until reinforcements).

  

## Modifier Sources

- **Reputation:** See [[Systems - Reputation]].

- **Recent Outcomes:** Momentum affects offer gates, DCs, and backup arrival timing.

- **Resources:** Consumables used or saved modify next encounter DCs (e.g., saved flashbang: −2 to first enemy check).

- **Terrain Control:** Secured vantage (−2 to ranged DC, +1 tactical options).
