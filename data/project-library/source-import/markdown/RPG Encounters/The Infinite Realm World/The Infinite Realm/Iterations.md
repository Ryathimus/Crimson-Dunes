An Iteration is, simply, a set of 9 highly intelligent Races, each typically inhabiting a separate world (with some exceptions). On top of this, there are then 9 total iterations, each with the same set of races but often with different variants (only 3 possible variants per race).

The arrival of the [Framework](https://infinite-realm.fandom.com/wiki/Framework "Framework") has meant that one by one, iterations are being prepared for and transported to the [Infinite Realm](https://infinite-realm.fandom.com/wiki/Infinite_Realm "Infinite Realm").

The following will use a dating system aligned to the arrival of the First Iteration. The first moment of arrival is designated as 'Year 0'. Note that the Infinite Realm Calendar is different to that of Earth, and likely any other old world, so the term 'year' is arbitrary.

For reference, the story begins with the Seventh Iteration.
