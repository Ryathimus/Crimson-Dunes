# RPG Branching Framework – README

  

This vault provides a reusable framework for running a branching, encounter-based RPG with strong narrative beats but multiple pathways to reach them.

  

## Quick Start

1. Read [[Plot - Main Arc]] for the fixed story beats.

2. Review [[Flowchart]] to see the branching structure.

3. Clone [[Encounter Template]] for each new encounter (e.g., [[Encounter - Inn Attack]], [[Encounter - Forest Clearing - Bandits]]).

4. Track outcomes and variables in [[Encounter Log]] and your [[Character Profile Template]].

5. Use systems notes: [[Systems - Checks]], [[Systems - Variables & Modifiers]], [[Systems - Rewards]], [[Systems - Reputation]].

  

## Core Concepts

- **Plot beats are fixed, paths are flexible.** Players may skip beats, arrive early/late, or change outcomes.

- **Encounters drive reputation, variables, and rewards** which gate or unlock branches.

- **NPC agency matters.** Key figures make decisions based on the player’s record and external factors.
